1  Network Port Scanner

OPEN SOURCE

github.com/ejbarraza/port-scanner

A dependency-free Python TCP port scanner built only on the standard library: threaded scanning, CIDR target support, quick / full / custom port profiles, banner grabbing and reverse DNS, with reports in text, JSON, CSV, and HTML.

  • Backed by 25 pytest tests, with GitHub Actions CI running the suite across Python 3.10–3.12.
  • Field-tested on a live subnet: found and fixed two real defects — a reverse-DNS stall on dead hosts and a Ctrl+C path that drained the probe queue — each covered by a regression test.

2  Virtual Lab Network Audit

HOMELAB

Findings: github.com/ejbarraza/port-scanner/tree/main/docs/lab-findings

Applied the scanner to a full VirtualBox NAT subnet (10.0.2.0/24, 254 hosts) from a Windows 11 VM, sweeping every address in under five minutes.

  • Mapped 7 open ports across the subnet, including SMB (445) and MSRPC (135), and documented what each exposed service is.
  • Recorded per-service remediation notes — whether each port should be exposed and how to close or restrict it.
